01 / A IDEIA

Conheça o CloudReports.

Cenário de e-commerce

Uma loja precisa compartilhar os pedidos com públicos diferentes. A equipe analisa os dados em uma planilha. A gestão recebe um documento pronto para leitura.

→

Um pedido. Duas formas de entregar a informação.

O usuário filtra as vendas, escolhe CSV ou PDF e gera o arquivo. O sistema prepara os dados, cria o relatório adequado e devolve o download.

Dados fictíciosExportação realAPI Node.js
O PROBLEMA

Novos formatos aumentam o acoplamento.

Se o fluxo conhece os detalhes de cada arquivo, ele precisa acompanhar cada mudança de formato.

A SOLUÇÃO

Delegar a criação para subclasses.

O fluxo trabalha com o contrato gerar(pedidos). Cada criador concreto fornece o produto correspondente.

✳

Objetivo da apresentação
Mostrar onde o objeto é criado, como o polimorfismo escolhe a implementação e como o fluxo usa o produto retornado.

02 / O PADRÃO

Leia o diagrama. Encontre no código.

↓ Baixar UML

O Factory Method declara um método de criação na classe base. As subclasses sobrescrevem esse método para fornecer diferentes produtos que seguem um contrato comum.

01

O criador conduz

Exportacao.executar() valida os dados e pede um relatório ao método fábrica.

02

A subclasse cria

ExportacaoPDF implementa criarRelatorio() e retorna new RelatorioPDF().

03

O produto entrega

O objeto recebe gerar(pedidos) e devolve os bytes, o nome e o tipo do arquivo.

Onde está o Factory Method?

Dentro do backend, entre o fluxo de exportação e os geradores de arquivo. A API escolhe a subclasse a partir do formato. O método sobrescrito dessa subclasse cria o produto.

De onde vêm os pedidos?

De uma base fictícia em lib/pedidos.js. Uma evolução poderia buscar os dados em um banco de dados, preservando o contrato dos relatórios.

Qual parte prova que usamos Factory Method?

A classe Exportacao chama this.criarRelatorio(). As subclasses sobrescrevem esse método e retornam produtos com o mesmo contrato. O mapa na API seleciona o criador, e a criação do produto acontece no método sobrescrito.

Como adicionar um relatório JSON?

Implemente RelatorioJSON com gerar(), crie ExportacaoJSON com criarRelatorio() e registre o formato na API e na interface. A nova subclasse reutiliza o fluxo de executar().

Qual é a desvantagem dessa organização?

O número de classes aumenta. Vale discutir se a flexibilidade compensa esse custo para o cenário. Aqui, a separação ajuda a demonstrar a evolução dos formatos e a criação polimórfica dos objetos.

Como isso se relaciona com arquitetura em nuvem?

O site envia uma requisição HTTP para uma função Node.js na Vercel. O padrão organiza a criação dos geradores dentro dessa função. A plataforma hospeda a aplicação, e o Factory Method organiza parte de seu código.
